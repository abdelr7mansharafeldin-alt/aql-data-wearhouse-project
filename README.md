# Data Warehouse and Analytics Project

Welcome to the **Data Warehouse and Analytics Project** repository! 🚀[cite: 1]
This project demonstrates a comprehensive data warehousing and analytics solution, from building a data warehouse to generating actionable insights. Designed as a portfolio project, it highlights industry best practices in data engineering and analytics.[cite: 1]

---

## 🚀 Project Requirements[cite: 1]

### Building the Data Warehouse (Data Engineering)[cite: 1]

#### Objective[cite: 1]
Develop a modern data warehouse using SQL Server to consolidate sales data, enabling analytical reporting and informed decision-making.[cite: 2]

#### Specifications[cite: 2]
- **Data Sources**: Import data from two source systems (ERP and CRM) provided as CSV files.[cite: 2]
- **Data Quality**: Cleanse and resolve data quality issues prior to analysis.[cite: 2]
- **Integration**: Combine both sources into a single, user-friendly data model designed for analytical queries.[cite: 2]
- **Scope**: Focus on the latest dataset only; historization of data is not required.[cite: 2]
- **Documentation**: Provide clear documentation of the data model to support both business stakeholders and analytics teams.[cite: 2]

---

### BI: Analytics & Reporting (Data Analytics)[cite: 2]

#### Objective[cite: 2]
Develop SQL-based analytics to deliver detailed insights into:[cite: 2]
- **Customer Behavior**[cite: 2]
- **Product Performance**[cite: 2]
- **Sales Trends**[cite: 2]

These insights empower stakeholders with key business metrics, enabling strategic decision-making.[cite: 2]
